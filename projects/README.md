# AI Engineering Portfolio Projects

This folder contains two additional, independently runnable engineering projects:

1. **Intelligent Workflow Automation** — an API-driven business workflow with idempotency, retries, event history and an optional webhook delivery adapter.
2. **LLM Observability Gateway** — task-aware model routing, OpenAI-compatible API calls, fallback, rate limiting, token/cost estimates and runtime metrics.

Each project has its own README, dependencies, source code and tests. They are portfolio demonstrations and should be run and understood before being described in an interview.
